2. Test A — Cashier settle deposit (cash)

  1. Open Cashier with your staff key.
  2. Choose Settle deposit.
  3. Select a guest who still needs a deposit.
  4. Choose Cash (no POS hardware needed for this QA).
  5. Confirm amount ≈ 20% deposit, then Settle.
  6. Check Inbox / calendar — stay should be confirmed / booked.

3. Test B — Calendar walk-in

  1. Open Calendar.
  2. Tap a green (free) cell for room + check-in.
  3. Enter guest details; set check-out for the full stay.
  4. Save — cell turns teal (booked) or amber (pending).
  5. Pending stays: open booking → Mark as booked after payment.

Figure 4 — Occupancy calendar (tap free cell to book).

4. Test C — Guest online Paystack deposit

  1. On the public site, pick dates → Rooms.
  2. Select a room → complete booking → Pay deposit.
  3. Pay with the test card above.
  4. Confirm success callback, then check Accounting / Inbox.

5. Test D — F&B for a booked guest

  1. Open Cashier → Order F&B or /staff/fnb.
  2. Search booked guest → add catalog lines → post to folio.
