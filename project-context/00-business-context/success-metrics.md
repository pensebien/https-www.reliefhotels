# Success Metrics

## Measurement Window

- **Initial Horizon:** First 90 days after production launch
- **Reporting Frequency:** Weekly dashboard + monthly review

## Primary KPI

### 1) Paid Online Bookings
- **Definition:** Number of completed paid bookings from web channel
- **Target:** **20 paid bookings/month**
- **Owner:** Tech Lead + Reservations Manager

## Secondary KPIs

### 2) Website Readiness
- **Definition:** Core pages and user paths are functional across desktop/mobile
- **Target:** 100% critical user journeys pass smoke tests
- **Owner:** Tech Lead

### 3) Booking Flow Reliability
- **Definition:** Reservation submission and payment-initiation complete without blocking errors
- **Target:** >= 98% successful booking form/API completion
- **Owner:** Tech Lead

### 4) Room Reservation Processing
- **Definition:** Reserved room request is captured and visible to operations
- **Target:** 100% of reservation requests stored and traceable
- **Owner:** Reservations Team

### 5) Manager Notification Delivery
- **Definition:** New booking/reservation alerts sent to manager via SMS/WhatsApp
- **Target:** >= 95% delivery success
- **Owner:** Operations + Tech Lead

### 6) Response Time
- **Definition:** Time between reservation submission and first manager/team response
- **Target:** <= 15 minutes during service hours
- **Owner:** Hotel Management

## KPI Data Sources

- Booking/payment API logs
- Reservation database/store entries
- Notification provider delivery logs (SMS/WhatsApp)
- Demo/dashboard and production analytics exports
