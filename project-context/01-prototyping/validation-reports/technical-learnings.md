# Technical Learnings

## Confirmed Learnings

1. Feature modularization by phase folders reduces merge conflicts.
2. Demo-mode checkout is useful for stakeholder presentations and early QA.
3. Localization fallback strategy prevents hard failures in partially translated locales.
4. Structured context documentation improves decision traceability across phases.

## Operational Learnings

1. Booking systems must include explicit human follow-up ownership.
2. Notifications are as critical as form capture for service quality.
3. Managers need concise, actionable alert format (guest, intent, urgency).

## Recommended Improvements

- Add notification retry queue + dead-letter logging
- Add SLA timer tracking from submission to first response
- Introduce role-based internal dashboard views
