# Prototype V2 - Experience + Events Conversion

## Objective

Validate demand and usability for event inquiries and curated experiences (Ibom/Hilton-inspired content strategy).

## Scope

- Meetings & Events teaser on homepage
- Signature Experiences teaser on homepage
- `/events` page with inquiry form
- `/dine-wine` page with reservation form

## Success Criteria

- Users can find event and dining options in under 2 clicks
- Event inquiry form and dining reservation form submit successfully
- Operations can view submission data for follow-up
